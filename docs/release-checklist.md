# 출시 체크리스트

## 제품과 안전

- [ ] 게시 전 자동 유해성 분류가 production 함수와 연결됨
- [ ] 게시글, 댓글, 사용자 신고가 운영자 큐에 도착함
- [ ] 차단한 사용자의 콘텐츠가 모든 피드에서 숨겨짐
- [ ] 고객지원 연락처와 신고 처리 SLA가 공개됨
- [ ] 개인정보처리방침, 이용약관, 커뮤니티 운영정책이 공개 URL에 있음
- [ ] 앱 내 계정삭제와 외부 계정삭제 요청 URL이 동작함
- [ ] AI 답변 오류 신고와 공식 출처 링크가 동작함

## 개인정보

- [ ] 여권번호와 외국인등록번호를 수집하지 않음
- [ ] 로그와 AI 요청 전에 고유식별정보 패턴을 마스킹함
- [ ] 채팅 보유기간과 삭제 방침을 공개함
- [ ] App Store Privacy와 Google Play Data safety 응답이 실제 동작과 일치함

## 빌드

- [ ] bundle identifier와 package name이 확정됨
- [ ] 아이콘, 스플래시, 스크린샷, 설명, 지원 URL이 준비됨
- [ ] `eas build --profile preview --platform all` 성공
- [ ] TestFlight와 Play 내부 테스트에서 핵심 흐름 확인
- [ ] production 환경에서 RLS 테스트 통과

실제 제출은 계정 소유자의 명시적 승인 후 수행합니다.
