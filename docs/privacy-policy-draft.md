# 개인정보처리방침 초안

이 문서는 법률 검토 전 제품 구현을 위한 초안입니다.

서비스는 계정 이메일, 표시 이름, 선호 언어, 대학, 체류자격, 체류만료일, 지역, 작성한 게시글과 댓글, 신고·차단 기록, 선택한 알림 설정을 처리할 수 있습니다. 여권번호와 외국인등록번호는 요구하지 않습니다.

수집 목적, 보유기간, 처리위탁, 국외이전, 이용자 권리, 계정삭제, 문의처는 실제 운영주체와 인프라가 확정된 뒤 구체적으로 작성해야 합니다. 이용자는 앱 설정에서 프로필·알림·익명 기본값을 변경하고 계정삭제를 시작할 수 있습니다. 삭제 시 법령상 보존이 필요한 항목을 제외한 계정 관련 데이터를 삭제하거나 익명화합니다.

앱은 이용약관, 개인정보 처리방침, 커뮤니티 운영정책의 문서 키·버전·동의 시각을 기록합니다. 정책 버전이 변경되면 다시 동의를 요청합니다. 마케팅 정보는 현재 MVP에서 발송하지 않으며, 향후 도입 시 선택 동의와 철회 이력을 별도로 관리해야 합니다.
